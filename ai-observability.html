Something has changed.

The experience begins with a calm scenario introduction instead of dropping users directly into a dense technical dashboard.

04 / Impact Check

So, is this actually a problem?

The design helps users move beyond “something changed” toward understanding impact, urgency, and whether action is needed.

Token usage

More tokens can increase operational cost.

Cost impact

The change may affect monthly spend if it continues.

Quality signal

The system helps check whether output quality improved or declined.

05 / What Changed

What changed?

The investigation flow points users toward recent system changes instead of forcing them to search blindly.

Prompt template updated

A recent prompt change may have affected summary length.

Embedding model stable

Not every system component changed, helping narrow the search.

Retrieved configuration updated

The system highlights changes that may explain the behaviour.

06 / Investigation Prompt

The timing looks suspicious.

Instead of asking users to interpret raw logs alone, the interface supports guided investigation with a clear next question.

Good place to start: Check whether summary length increased after the prompt template update. Then compare cost, latency, and output quality before and after the change.
07 / Environment Check

08 / Root Cause

There’s the difference.

The design leads the user from alert to evidence, then toward a likely root cause.

Before

Summaries were concise and focused on the most relevant candidate information.

After

A revised prompt encouraged longer summaries, increasing output length and cost.

09 / Project Outro

From anomaly to understanding.

The final experience shows how an observability tool can support investigation, not just monitoring.

Why this design

What happened? What does it mean? What should I do next?

This case study reframes AI observability around decision-making. The goal is not only to show metrics, but to help teams understand what changed, why it matters, and how to investigate with confidence.
